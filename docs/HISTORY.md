## 2026-07-22 — Claude 글로벌 훅 경량화

- 일반 Bash 호출에서 하위 훅 3개를 항상 실행하던 구조를 필요한 검사만 실행하도록 변경했습니다.
- 문서 Edit 자동 백업을 중단했습니다. Git과 편집 도구의 복구 기능이 있는데도 백업이 계속 쌓여 속도와 관리 비용을 높였기 때문입니다.
- 일반 `git push`와 브랜치 전환은 허용하고, `reset --hard`, 강제 push, 문서 직접 쓰기처럼 복구하기 어려운 작업만 차단합니다.
- 측정한 일반 Bash 훅 평균 시간이 약 4,230ms에서 898ms로 줄었습니다.
