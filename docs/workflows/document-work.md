# 문서 작업 안내

별도 문서 체크리스트와 목차 승인을 일괄 요구하던 [이전 절차](../archive/2026-09-10-retired-guides/document-work.md)는 과거 기록이며 현재 작업 지침으로 적용하지 않습니다.
