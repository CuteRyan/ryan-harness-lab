# Day 25 — 2026-07-31 — 편집 권한 경계 정리와 Claude·Codex 교차 검토 스킬 신설

## 1. 전역 편집 승인 훅 제거

- Claude의 모든 `Write`, `Edit`, `NotebookEdit` 호출마다 사용자 확인을 요구하던 `write-approval-guard.ps1`과 활성 설정 연결을 제거했습니다.
- 삭제 명령 확인과 위험한 Git 명령 차단은 유지했습니다.
- **왜**: 명시하지 않은 편집을 막으려는 목적에는 맞았지만, 승인된 정상 작업도 편집마다 중단해 비용이 지나치게 컸습니다.
- 변경 파일: `settings/settings.template.json`, `~/.claude/settings.json`
- 검증: 활성 `PreToolUse` matcher가 `Bash`만 남았고 편집 승인 훅 참조와 운영 파일이 제거된 것을 확인했습니다.

## 2. Codex·Claude 작업 권한 지침 명확화

- 점검·분석·진단·설명·검토·요약·비교·상태 보고는 읽기 전용으로 처리하도록 양쪽 전역 지침에 추가했습니다.
- 사용자가 변경을 명확히 요청하지 않으면 파일이나 외부 상태를 바꾸지 않고, 승인된 범위의 되돌릴 수 있는 편집은 건별 재확인 없이 진행하도록 정리했습니다.
- **왜**: 전역 훅 대신 요청의 의도와 승인 범위를 지침에서 직접 구분해 과잉 실행과 반복 확인을 함께 줄이기 위해서입니다.
- 변경 파일: `settings/AGENTS.global.md`, `settings/CLAUDE.global.md`
- 검증: Codex·Claude 운영본과 공통 원본의 일치를 확인했습니다.

## 3. `cross-agent-review` 스킬 신설 및 독립 리뷰 반영

- 주제와 날짜별 공유 MD에서 Claude와 Codex가 작성자를 표시하며 의견을 이어 쓰고, 사용자 지시로만 완료하는 공통 스킬을 만들었습니다.
- 새 검토는 `docs/cross-review/<topic-slug>-YYYY-MM-DD.md`에 생성하며, 같은 주제라도 날짜가 다르면 별도 파일로 관리합니다.
- 독립 리뷰 에이전트의 지적을 대조해 완료 표현 구분, 정의되지 않은 재개 기능 제거, 안전한 slug 규칙, 한 번에 한 에이전트만 작성하는 규칙을 반영했습니다.
- 검토 파일 작성은 검토 대상 코드·문서 수정 권한을 부여하지 않도록 경계를 명시했습니다.
- **왜**: 같은 작업을 수행하는 Claude와 Codex가 상대방의 결과와 근거를 잃지 않고 릴레이로 검토할 수 있게 하기 위해서입니다.
- 변경 파일: `skills/cross-agent-review/SKILL.md`, `skills/cross-agent-review/assets/review-template.md`, `skills/cross-agent-review/agents/openai.yaml`
- 검증: 스킬 형식 검사, 시작·답변·완료 흐름 검사, 리뷰 반영 검사와 양쪽 운영본 일치를 확인했습니다.
