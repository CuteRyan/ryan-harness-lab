# 2026-09-25 — 공동 기록 소유와 선택적 피드백

## 1. 팀 공동 기록과 필요한 때 읽는 피드백

- 결론: [에이전트 구조](../agent-structure.md#documents)에 팀이 지정한 작성자·최종 검토자가 공동 history·handoff 원본 한 벌을 유지할 수 있도록 명시했다. 개인은 같은 본문을 다시 쓰지 않고 연결하며 역할·메모리·작업 공간·실행 상태는 독립적으로 유지한다.
- 변경·이유: 중복 기록을 줄이되 책임과 확인 절차를 유지한다. 기록 수락과 종료 확인은 프로젝트 실행 계약이 맡는다. [자체 피드백](../agent-structure.md#self-feedback)은 근거가 있을 때만 개인 또는 팀 원본에 제안하고, 엔진·모델에 관계없이 목차를 통해 관련 상세만 읽는다. 제안 부재는 종료를 막지 않으며, 지침 반영에 필요한 사람 승인은 유지한다.
- 검증: 내부 절 링크 20개, 코드 펜스, 네 가지 필수 원칙을 확인했다. PA 참조 사본과 원본의 바이트·SHA-256이 일치한다(`369af6baf6abd4071c0755a9b4b5acaecc70364e359f014be4f2d2b7eab5ee82`). 이 변경은 공통 설계 문서이며 런타임 구현·배포와 사용자별 설정은 포함하지 않는다.
