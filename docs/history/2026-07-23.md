# 2026-07-23 — Day 24: 사용하지 않는 전역 커밋 훅 정리

## 결론

호출되지 않는 `pre-commit-guard.sh`를 활성 영역에서 제거했다. 전역 `git commit` 때 모든 프로젝트에 같은 lint·pytest를 강제하는 방식은 되살리지 않는다.

## 변경과 이유

- 프로젝트의 `hooks/pre-commit-guard.sh`는 Git에서 제거했다.
- Claude 운영본은 삭제하지 않고 `~/.claude/.archive/2026-07-23/pre-commit-guard.sh`로 옮겼다.
- 프로젝트별 검사는 각 저장소의 CI나 자체 pre-commit 설정이 맡는다. 전역 검사는 느리고 프로젝트와 맞지 않는 테스트를 실행할 수 있기 때문이다.
- 과거 설계·히스토리 문서의 파일명 언급은 당시 사실을 보존했고, 전역 검사를 호출하지 않는 회귀 테스트도 유지했다.
