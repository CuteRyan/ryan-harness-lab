# 글로벌 지침과 PA 메모리 축소

- 결론: 작은 해결, 필요한 제약, 에이전트의 판단, 결과 검증을 Codex·Claude 공통 원칙으로 반영했다.
- 변경: 글로벌 지침 원본 2개와 Claude 규칙 3개를 수정하고 대응 운영본에 복사했다. PA 메모리 인덱스는 89줄·15,078바이트에서 20줄·972바이트로 줄였다. 이전 인덱스는 같은 메모리 폴더의 `archive/2026-09-09-MEMORY.md`에 보존하고 주제 파일 72개는 유지했다.
