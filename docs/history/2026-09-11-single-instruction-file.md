# 글로벌 지침을 한 장으로 합치고 규칙 폴더를 없앰

- 결론: 클로드와 코덱스의 기본 지침이 서로 달랐다. 클로드는 글로벌 1장에 `rules/` 8장을 더 읽고, 코덱스는 글로벌 1장만 읽었기 때문이다. 지침을 한 장에 모아 두 환경이 같은 내용을 읽게 했다. 클로드가 읽는 양은 173줄에서 75줄로 줄었다.
- 근거: 코덱스 CLI 0.154.0 바이너리에서 지침 관련 설정 키가 `project_doc_max_bytes`와 `project_doc_fallback_filenames`뿐이고 규칙 폴더를 읽는 기능이 없음을 확인했다. `~/.codex/rules/default.rules`는 명령어 허용 목록이며 작성 지침이 아니다. 따라서 `rules/` 층은 클로드에서만 존재할 수 있었다.
- 변경: `rules/` 8장을 없애고 내용을 `settings/CLAUDE.global.md`와 `settings/AGENTS.global.md`의 섹션으로 옮겼다. 두 파일은 하나의 본문에서 생성하며 실행 환경 관련 5줄만 다르다. 코덱스 쪽이 2줄 긴 것은 협업 도구 관련 줄이 코덱스에만 필요해서다.
- 변경: 주인님이 반복해 지적하신 규칙 4개를 새로 넣었다. 영어 문서의 한국어 번역 병기, 주인님이 정할 값은 묻거나 샘플 먼저, 요청 범위를 임의로 줄이지 않기, 「계속해」나 배포 요청은 커밋·푸시 허락이 아님. 다섯 번째였던 AI 워커 범위 축소 금지는 일반형으로 바꿔 범위 규칙에 합쳤다.
- 검증: 합치기 전 문장 71개를 새 파일과 대조해 글자 그대로 남지 않은 16개의 새 자리를 하나씩 확인했다. 모두 다른 문장에 합쳐졌고 사라진 규칙은 없다. 원본과 운영본 2쌍을 복사 후 바이트 비교로 확인했다. 저장소의 PowerShell 테스트 2개는 pytest 대상이 아니라 실행하지 않았다.
- 보존: 이번 정리와 무관한 미커밋 변경 3개(`docs/index.md` 1줄, `skills/handoff/SKILL.md` 5줄, 미추적 `docs/agent-structure.md`)는 건드리지 않았다. 다른 세션 작업이므로 이 커밋에 담지 않는다.
- 기록: 옛 `rules/` 8장 전문은 직전 커밋 `f282ad1`에 그대로 있다. 되돌릴 때는 거기서 꺼낸다.
