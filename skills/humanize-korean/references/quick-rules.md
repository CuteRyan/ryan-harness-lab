# 자연스러운 한국어 글 다듬기 기준

원문의 뜻과 말투를 유지하면서 분명히 어색한 부분만 고칩니다. 아래 예시는 강제 치환표가 아닙니다. 문맥상 의미가 그대로일 때만 적용합니다.

## 우선순위

1. 의미와 사실 보존
2. 글의 목적, 말투, 독자층, 문서 구조 보존
3. 어색한 표현을 필요한 만큼만 수정
4. 이미 자연스러운 문장은 유지

자연스럽게 보이게 만드는 것보다 원문을 정확히 지키는 일이 우선입니다.

## 반드시 보존할 것

- 사실, 주장, 수치, 날짜, 이름, 인용문, 링크
- 가능성·추정·의무의 강도
- 과거·현재·미래 시제
- 긍정과 부정, 조건, 원인과 결과
- 격식 정도와 화자의 태도
- 제목, 목록, 표, 문단 순서와 같은 문서 구조
- 독자에게 익숙한 기술 용어

익숙한 영어 기술 용어를 억지로 번역하지 않습니다. 자연스러운 한국어 표현이 없으면 영어를 유지하고, 설명이 필요할 때만 첫 등장에 짧은 한국어 뜻을 붙입니다. 새로운 한국어 명칭을 만들지 않습니다.

## 고칠 수 있는 표현

| 기준 | 살펴볼 표현 | 수정 원칙 |
|---|---|---|
| A-1 | `~에 대해`, `~에 대해서`가 반복됨 | 목적어로 바로 연결해도 뜻이 같을 때만 줄임 |
| A-3 | `~에 있어서` | 문맥에 맞는 `~에서`, `~할 때` 등으로 간단히 바꿈 |
| A-8 | `~되어지다` 같은 이중 피동 | 행위자와 의미가 분명할 때 단일 피동이나 능동으로 바꿈 |
| C-11 | 연결어미 바로 뒤의 불필요한 쉼표 | 호흡이나 의미 구분에 필요하지 않을 때만 삭제 |
| D-1 | `결론적으로`, `이를 통해` 같은 상투 표현의 반복 | 정보가 없는 반복만 줄이고 필요한 논리 연결은 유지 |
| F-5 | 뜻이 흐린 추상 명사의 연쇄 | 원문의 개념을 바꾸지 않는 범위에서 풀어 씀 |
| H-1 | 문장 첫머리 접속사의 반복 | 흐름에 필요하지 않은 것만 삭제 |
| I-1 | `~인 것이다`, `~한 것이다`의 반복 | 강조나 설명 기능이 없을 때만 평서형으로 줄임 |

같은 표현이 있다는 이유만으로 고치지 않습니다. 반복 때문에 읽기 어렵거나 번역한 문장처럼 어색할 때만 수정합니다.

## 자동으로 하지 않을 것

- `할 수 있다`를 단정형으로 바꾸기
- 미래형이나 추정 표현을 현재의 확정 표현으로 바꾸기
- 권고를 의무로, 의무를 권고로 바꾸기
- 목록이나 표를 산문으로 바꾸기
- 제목, 굵은 글씨, 인용부호, 이모지를 일괄 삭제하기
- 문장 길이를 맞추려고 일부러 늘이거나 줄이기
- 격식체를 구어체로 바꾸기
- 전문 용어를 낯선 한국어로 바꾸기
- 점수나 등급을 맞추기 위해 멀쩡한 문장을 수정하기

## 확인 방법

수정한 부분마다 다음을 확인합니다.

1. 원문의 뜻과 확신 정도가 같은가?
2. 새로운 사실이나 평가를 넣지 않았는가?
3. 이름·수치·날짜·인용·링크가 그대로인가?
4. 문서 구조와 말투가 유지됐는가?
5. 고치기 전보다 실제로 읽기 쉬워졌는가?

하나라도 확신할 수 없으면 원문을 유지합니다. 전체 변경률이 30%를 넘으면 이유를 알리고, 50%를 넘으면 중단합니다.
