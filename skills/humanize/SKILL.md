# /humanize

## 입력

$ARGUMENTS

## 실행

1. 입력이 없으면 다듬을 글이나 파일 경로를 요청합니다.
2. `.txt` 또는 `.md` 경로이면 파일을 읽고, 아니면 입력 문장을 그대로 사용합니다.
3. `humanize-korean` 스킬을 실행합니다. `--strict`는 사용자가 직접 지정했을 때만 전달합니다.
4. 변경률과 내용 보존 결과를 한 줄로 먼저 알린 뒤, 다듬은 본문과 짧은 변경 요약을 보여줍니다.

장르나 수정 강도가 함께 지정되면 그대로 전달합니다. 사실 추가, 번역, 단순 맞춤법 교정은 이 명령의 범위가 아닙니다.
