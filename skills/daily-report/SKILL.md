# Slack 데일리 작성

오늘 업무를 다음 네 줄로 정리한다.

## 정보 확인

다음 순서로 사실을 확인한다.

1. 사용자가 직접 말한 내용
2. 현재 대화에서 오늘 수행한 작업
3. 프로젝트의 오늘 히스토리
4. 필요할 때만 Git 변경 내역

Git 파일명만 보고 업무 성과를 추측하지 않는다. `막힘`이 없으면 `없음`으로 쓴다. 나머지 항목의 근거가 부족하면 결과를 만들기 전에 부족한 내용만 한 번 묻는다.

## 항목 구분

- `완료`: 오늘 끝내 결과가 나온 일
- `진행`: 시작했지만 아직 끝나지 않은 일
- `막힘`: 정보·승인·외부 의존성 때문에 진행할 수 없는 일
- `내일 핵심`: 내일 가장 먼저 처리할 구체적인 행동 한 가지

완료와 진행에 같은 일을 반복하지 않는다. 일반적인 걱정은 막힘으로 부풀리지 않는다. 내일 핵심은 근거가 있는 계획이나 미완료 작업에서 고른다.

## 출력

아래 네 줄만 출력한다. 제목, 날짜, 인사말, 불릿, 코드블록, 추가 설명은 붙이지 않는다.

```text
완료: 일본 웰니스 브랜드 12개 1차 조사
진행: 에가톳 제안 훅과 일본 탤런트 후보 정리
막힘: 일본 탤런트 예상 단가 정보 부족
내일 핵심: 담당자 5명 연락 경로 확보 및 CRM 등록
```

각 항목은 한 줄로 짧게 쓰고, 내부 파일명이나 구현 세부사항보다 팀원이 알아야 할 결과와 행동을 적는다.
