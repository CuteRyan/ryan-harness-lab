# Checklist

사용자가 체크리스트를 직접 요청했을 때만 사용한다.

## 실행 조건

다음 경우에만 실행한다.

- 사용자가 `/checklist`를 입력함
- 사용자가 “체크리스트를 만들어 주세요”라고 명시함

일반적인 수정·구현·문서 작성 요청에는 자동으로 실행하지 않는다. 작업을 시작하기 위한 별도 승인도 요구하지 않는다.

## 진행 방법

1. 할 일을 2~7개 항목으로 정리한다.
2. 사용자가 요청한 작업을 진행하며 완료 항목을 표시한다.
3. 실제 파일과 검사 결과를 확인하고 짧게 보고한다.

작업 범위가 달라지거나 되돌리기 어려운 행동이 필요해지면 그 부분만 사용자에게 확인한다.

## 기본 양식

```markdown
# 체크리스트: 작업명

- [ ] 작업 항목
- [ ] 확인 항목
```

필요할 때만 대상 파일이나 복구 방법을 한두 줄 덧붙인다. 배경 설명, 단계별 승인, 체크리스트 전문 재출력은 요구하지 않는다.

## 다른 기록과의 관계

- 장기 할 일은 사용자가 `/todo`를 요청했을 때만 옮긴다.
- 세션 인계는 사용자가 `/handoff`를 요청했을 때만 만든다.
- 완료 기록은 사용자가 `/project-history`를 요청했을 때만 남긴다.
- 위 작업을 자동으로 함께 실행하지 않는다.

## 파일 위치

- 현재 작업 목록: `{프로젝트 루트}/.checklist.md`
- 완료 후 보관은 사용자가 요청했을 때만 한다.

## 관리 위치

- 작업본: `Harness-engineering/skills/checklist/SKILL.md`
- Claude 사용본: `~/.claude/skills/checklist/SKILL.md`
