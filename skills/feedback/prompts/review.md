# 리뷰 지침

같은 폴더에 있는 대상 파일 하나만 검토하세요. `review.md`는 지시문이므로 검토 대상이 아닙니다. 다른 폴더는 탐색하지 마세요.

실제로 확인되는 문제만 보고하세요. 버그, 보안 문제, 계약 위반, 빠진 오류 처리처럼 동작이나 유지보수에 영향을 주는 내용을 우선합니다. 취향 차이, 막연한 개선 제안, 칭찬은 생략합니다.

각 문제는 다음 형식으로 한 줄씩 작성하세요.

```text
[높음] file.py:42 - 근거: 입력값이 확인되지 않은 채 SQL 문자열에 들어감
```

태그는 `[치명]`, `[높음]`, `[중간]`, `[낮음]` 중 하나를 사용합니다. 줄 번호와 짧은 근거를 함께 적고, 확실하지 않은 내용은 문제로 단정하지 마세요.

확인된 문제가 없으면 다음 한 줄만 작성하세요.

```text
[낮음] 없음 - 근거: 확인된 결함 없음
```

한국어로 짧게 답하세요.
